Función especial

El conjunto de Mandelbrot

Para cada punto c del plano se itera z ↦ z{{ shownExponent }} + c desde z = 0. La altura cuenta cuántas iteraciones tarda en escapar; la meseta más alta es el conjunto.

Iteración
z ↦ z^{{ shownExponent }} + c
Dominio
Re c, Im c ∈ [−2, 2]
Rejilla
500 × 500 puntos
Máximo
100 iteraciones

Con d = 2 es el conjunto clásico; con exponentes mayores aparecen d − 1 lóbulos.
